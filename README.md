# Mobile Restaurant Menu

A simple interactive restaurant ordering app built with **HTML, CSS, and Vanilla JavaScript**.
Users can browse menu items, add them to a cart, remove items, and complete a mock payment flow.

---

## 🚀 Features

* Display food menu dynamically from a data file
* Add items to cart
* Remove items from cart
* Auto-calculated total price
* Payment form modal
* Success message after order completion
* Responsive mobile-friendly layout

---

## 🧠 How It Works

1. Menu items are rendered from a JavaScript array (`menu`)
2. Clicking **"+"** adds items to the cart
3. Cart updates dynamically using state (`storeSelectedItem`)
4. Users can remove items from the cart
5. Clicking **Complete Order** opens a payment form
6. After submitting payment, a thank-you message is shown
